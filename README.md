# DevOps Labs

A collection of hands-on DevOps projects, scripts, and experiments built while learning and practicing Linux, system administration, automation, networking, monitoring, and DevOps tooling.

## Projects

### Server Performance Stats

A Bash script that displays basic Linux server performance statistics, including CPU usage, memory usage, disk usage, and the top processes by resource consumption.

**Project:** [roadmap.sh/server-stats](https://roadmap.sh/projects/server-stats)

**Directory:** [`Server-Performance-Stats/`](./Server-Performance-Stats/)

---

### Log Archive Tool

A Bash CLI tool that compresses a log directory into a `.tar.gz` archive and records when the archive was created.

**Project:** [roadmap.sh/log-archive-tool](https://roadmap.sh/projects/log-archive-tool)

**Directory:** [`Log-Archive/`](./Log-Archive/)

---

### Log Analysis Tool

A Bash CLI tool that analyzes Nginx access logs and displays the top 5 IP addresses, requested paths, response status codes, and user agents.

**Project:** [roadmap.sh/nginx-log-analyser](https://roadmap.sh/projects/nginx-log-analyser)

**Directory:** [`Log-Analysis/`](./Log-Analysis/)

---

### GitHub Deployment Workflow

A GitHub Actions workflow that automatically deploys a static website to GitHub Pages when changes are pushed to the `main` branch.

**Website:** [View live website](https://abdev314.github.io/devops-labs/)

**Directory:** [`gh-deployment-workflow/`](./gh-deployment-workflow/)
